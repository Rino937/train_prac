# Day 1 - HTML 핵심 태그 정리

## 1. 문서 구조 태그
* **`<head>`** : 웹페이지의 제목("title"), 문자 인코딩("meta"), 외부 스타일시트 연결 등 화면에 직접 보이지 않는 문서의 메타데이터를 담는 영역.
* **`<body>`** : 텍스트, 이미지, 표, 입력 폼 등 브라우저 화면에 실제로 출력되는 본문 콘텐츠 잔체를 담는 영역.

## 2. 텍스트 및 레이아웃 태그
* **`<h1>` ~ `<h6>`** : 문서의 제목과 소제목을 나타내는 태그로, 숫자가 작을수록 글자 크기가 크고 중요도가 높다.
* **`<p>`** : 하나의 문단(Paragraph)을 정의할 때 사용하며, 태그 위아래로 기본 여백이 자동으로 생성된다.
* **`<hr>`** : 문단이나 섹션의 주제가 바뀔 때 가로 구분선을 그어 시각적으로 영역을 분리한다.

## 3. 목록(List) 태그
* **`<ul>`** : 비순서 목록을 만들며, 각 항목 앞에 기호가 붙는다.
* **`<ol>`** : 순서 목록을 만들며, 각 항목 앞에 숫자나 알파벳이 차례대로 붙는다.
* **`<li>`** : `<ul>`이나 `<ol>` 태그 내부에서 개별 목록 아이템을 하나씩 정의할 때 사용한다.

## 4. 미디어 및 링크 태그
* **`<img>`** : 웹페이지에 이미지를 삽입하는 단일 태그로, `src` 속성으로 이미지 경로를, `alt` 속성으로 대체 텍스트를 지정한다.
* **`<a>`** : 다른 웹페이지나 외부 사이트(GitHub 등)로 이동하는 하이퍼링크를 생성하며, `href` 속성에 이동할 주소를 입력한다.

## 5. 표(Table) 태그
* **`<table>`** : 행과 열로 이루어진 표 전체의 외곽 틀을 정의한다.
* **`<thead>`** : 표의 헤더 영역을 그룹화할 때 사용한다.
* **`<tbody>`** : 표의 본문 영역을 그룹화할 때 사용한다.
* **`<tr>`** : 표 내부에서 가로 한 줄을 만든다.
* **`<th>`** : 표의 제목 셀을 정의하며, 텍스트가 자동으로 굵게 표시되고 가운데 정렬된다.
* **`<td>`** : 표의 일반 데이터 셀을 정의한다.

## 6. 폼(Form) 및 입력 태그
* **`<form>`** : 사용자가 입력한 데이터를 서버로 전송하기 위한 입력 양식 전체 영역을 감싸는 태그.
* **`<input>`** : 텍스트, 이메일, 비밀번호, 체크박스 등 사용자로부터 다양한 형태의 데이터를 입력받는 단일 태그.
* **`<button>`** : 클릭 가능한 버튼을 생성하며, 폼 내부에서 데이터를 제출하거나 초기화할 때 주로 사용.
