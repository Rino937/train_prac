# CSS 핵심 개념 정리

## 1. CSS란?
* HTML로 작성된 웹 문서의 구조에 색상, 글꼴, 여백, 레이아웃 등 시각적인 디자인을 입히는 스타일 시트 언어입니다. 문서의 내용(HTML)과 표현(CSS)을 분리하여 웹페이지의 유지보수성과 재사용성을 높여줍니다.

## 2. CSS 적용 방식 3가지
* **Inline CSS (인라인 방식)** : HTML 태그 내부에 `style` 속성을 직접 작성하여 스타일을 적용하는 방식으로, 해당 요소 하나에만 즉각 적용되며 우선순위가 가장 높다.
* **Internal CSS (내부 스타일 시트)** : HTML 문서의 `<head>` 영역 안에 `<style>` 태그를 만들고 그 안에 CSS 코드를 모아 작성하는 방식으로, 해당 HTML 파일 전체에 스타일이 적용된다.
* **External CSS (외부 스타일 시트)** : 별도의 `.css` 파일을 생성한 뒤 HTML의 `<link>` 태그로 연결하는 방식으로, 여러 웹페이지에서 동일한 스타일을 공유하고 관리하기에 가장 권장되는 방식이다.

## 3. CSS Selector (선택자)
* **전체 선택자 (`*`)** : HTML 문서 내의 모든 요소를 한꺼번에 선택할 때 사용하며, 주로 브라우저 기본 여백을 초기화할 때 활용한다.
* **태그 선택자 (`태그명`)** : 지정한 HTML 태그 이름(예: `p`, `div`, `h1`)에 해당하는 모든 요소를 선택한다.
* **클래스 선택자 (`.클래스명`)** : HTML 태그의 `class` 속성값 앞에 마침표(`.`)를 붙여 선택하며, 여러 요소에 공통된 스타일을 반복해서 재사용할 때 주로 쓴다.
* **아이디 선택자 (`#아이디명`)** : HTML 태그의 `id` 속성값 앞에 샵(`#`)을 붙여 선택하며, 문서 내에서 단 하나뿐인 고유한 요소를 지정할 때 사용한다.

## 4. style 속성
* **`style` 속성** : HTML 요소에 CSS 선언(`속성: 값;`)을 직접 부여할 때 사용하는 HTML 전역 속성으로, 세미콜론(`;`)으로 구분하여 여러 개의 디자인 속성을 한 줄에 나열할 수 있다.

## 5. Text 관련 속성
* **`font-size`** : 텍스트의 글자 크기를 지정하며, 주로 `px`(픽셀), `rem`, `em`, `%` 등의 단위를 사용한다.
* **`font-weight`** : 글자의 굵기를 조절하며, `normal`(기본, 400), `bold`(굵게, 700) 키워드나 `100`~`900` 사이의 숫자로 지정한다.
* **`text-align`** : 블록 요소 내부에 있는 텍스트나 인라인 요소의 가로 정렬 방식(`left`, `center`, `right`, `justify`)을 지정한다.

## 6. Box Model (박스 모델) 관련 속성
* **`content`** : 텍스트나 이미지 등 요소의 실제 알맹이(내용물)가 표시되는 가장 안쪽의 핵심 영역이다.
* **`width` / `height`** : 요소의 가로 너비(`width`)와 세로 높이(`height`)를 지정하며, 기본 상태에서는 `content` 영역의 크기를 의미한다.
* **`padding` (안쪽 여백)** : `content` 영역과 테두리(`border`) 사이의 안쪽 빈 공간을 설정한다.
* **`border` (테두리)** : 요소의 바깥쪽 경계를 감싸는 테두리 선으로, 굵기·선 종류·색상을 함께 지정한다.
* **`margin` (바깥쪽 여백)** : 테두리(`border`) 바깥쪽의 빈 공간으로, 이웃한 다른 HTML 요소들과의 간격을 띄울 때 사용한다.
* **`box-sizing`** : 요소의 너비(`width`)와 높이(`height`)를 계산하는 기준을 정하는 속성이다. 기본값인 `content-box`는 순수 내용물 크기만 기준으로 삼고, 실무에서 주로 쓰는 `border-box`는 안쪽 여백(`padding`)과 테두리(`border`)까지 모두 포함하여 전체 크기를 고정한다.
